| 项目 | 内容 |
| --- | --- |
| 版本 | V2.0 |
| 生产环境 | `https://43.155.130.69`（示例;替换为你的服务器地址） |
| 控制台 API | `/api/v1`（JWT Bearer） |
| 开放 API | `/open-api/v1`（API Key + HMAC 签名） |
| 参考 | [03-API接口文档.md](03-API接口文档.md) / [05-开发者接入指南.md](05-开发者接入指南.md) |

## 1. 三步接入

```
创建项目 → 拿凭证 → 推送事件(签名) → 页面查看时间线/AI摘要/问答
```

**① 创建项目**（自动生成 `apiKey` + `apiSecret`，仅此一次明文展示）：

```bash
curl -X POST $SERVER/api/v1/projects \
  -H "Authorization: Bearer <JWT>" -H 'Content-Type: application/json' \
  -d '{"projectKey":"pay-platform","name":"支付平台","repoUrl":"https://github.com/x/pay.git"}'
# → { apiKey: "evo_xxx", apiSecret: "hex64" }
```

**② 推送事件**（HMAC-SHA256 签名，**必须对原始请求体原样签名**）：

```bash
BODY='{"protocolVersion":"v1","eventId":"e-001","projectKey":"pay-platform","appKey":"payment-service","eventType":"CODE_COMMIT","occurredAt":"2026-08-02T14:10:00+08:00","source":"GITLAB_WEBHOOK","idempotencyKey":"gitlab:pay-platform:push:abc","payload":{"branch":"main","commitSha":"abc","authorName":"wangwu","message":"feat: xxx","files":[]},"blobRef":null}'
SIG=$(printf '%s' "$BODY" | openssl dgst -sha256 -hmac "$API_SECRET" | awk '{print $2}')
curl -X POST $SERVER/open-api/v1/events -H "X-EvoTrace-Api-Key: $API_KEY" \
  -H "X-EvoTrace-Signature: $SIG" -H 'Content-Type: application/json' -d "$BODY"
# → { success: true, data: { eventId, duplicated: false } }
```

**③ 验证**：页面时间线出现事件 → 数十秒后 AI 摘要 DONE → 演化问答可检索提问。

## 2. 事件协议速查

**请求体 (Envelope v1)**：

```json
{
  "protocolVersion": "v1",
  "eventId": "唯一事件ID",
  "projectKey": "项目标识",
  "appKey": "应用标识",
  "eventType": "CODE_COMMIT",
  "occurredAt": "2026-08-02T14:30:00+08:00",
  "source": "GITLAB_WEBHOOK",
  "idempotencyKey": "业务唯一键,重复推送自动去重",
  "payload": { "事件类型对应的载荷" },
  "blobRef": null
}
```

| eventType | 载荷要点 |
| --- | --- |
| `CODE_COMMIT` | branch / commitSha / authorName / message / files[] |
| `MR_MERGED` | 同 CODE_COMMIT |
| `RELEASE_TAG` | tag / commitSha / message |
| `INVENTORY_REPORT` | 依赖/配置/API 清单 |
| `CONFIG_CHANGE` | configCenter / keys[] / description |
| `DDL_CHANGE` | database / ddl / description |
| `DEPLOY_RECORD` | 部署记录 |

**约束**：
- `source` **必须是枚举**：`CLI / GITLAB_WEBHOOK / GITHUB_WEBHOOK / GITEE_WEBHOOK / OPEN_API / JAVA_SDK / FEISHU / JIRA`（自定义值报 500）
- 大 diff（>256KB）先 `POST /open-api/v1/blobs` 拿 `blobRef` 再引用
- 重复推送同 `idempotencyKey` 自动去重（`duplicated: true`）

## 3. 三对接方式对比

| 方式 | 适用场景 | 入口 |
| --- | --- | --- |
| **GitLab/GitHub Webhook** | 仓库事件全自动 | 仓库 Settings → Webhooks → `$SERVER/open-api/v1/webhooks/gitlab`(或 `/github`),无需签名。GitLab 若配置 `GITLAB_TOKEN`，push 会自动拉 commit diff 入库 |
| **开放 REST API** | 任意系统/CI 脚本 | `$SERVER/open-api/v1/events`(签名见 §1) |
| **Java SDK Starter** | Spring Boot 应用 | 引入 `evotrace-sdk-java`,自动上报依赖/配置/API 清单 |

## 4. 常见错误排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 401 | API Key 错 / 签名错 | 签名必须对**原始请求体**计算;凭证过期需页面「轮换」 |
| 500 + `Enum` 相关 | `source` 非枚举值 | 改用枚举值(见 §2) |
| 500 + 其他 | payload 字段不符 | 对照事件类型载荷 |
| 摘要 `FAILED` | AI 调用失败(超时/限流) | 检查 AI 模型配置的 Key 与额度;等待自动重试 |
| 摘要 `PENDING` 长期不变 | 模型未配置 Key | 「AI 模型配置」页配置并测试连接 |
| 问答检索不到 | 事件无摘要(非 CODE_COMMIT 事件当前不生成摘要) | 推送 CODE_COMMIT 事件;或补充 DDL/CONFIG 摘要能力 |

## 5. 完整对接示例（Python）

```python
import hmac, hashlib, json, urllib.request

SERVER, API_KEY, API_SECRET = "http://43.155.130.69", "evo_xxx", "hex64"

def push_event(ev):
    body = json.dumps({"protocolVersion": "v1", "projectKey": "pay-platform",
                       "appKey": "payment-service", "blobRef": None, **ev},
                      ensure_ascii=False).encode()
    sig = hmac.new(API_SECRET.encode(), body, hashlib.sha256).hexdigest()
    req = urllib.request.Request(f"{SERVER}/open-api/v1/events", data=body,
        headers={"Content-Type": "application/json",
                 "X-EvoTrace-Api-Key": API_KEY, "X-EvoTrace-Signature": sig})
    return json.loads(urllib.request.urlopen(req).read())

push_event({"eventId": "e-001", "eventType": "CODE_COMMIT",
            "occurredAt": "2026-08-02T14:10:00+08:00", "source": "GITLAB_WEBHOOK",
            "idempotencyKey": "gitlab:pay-platform:push:abc",
            "payload": {"branch": "main", "commitSha": "abc", "authorName": "wangwu",
                        "message": "feat: xxx", "files": []}})
```
