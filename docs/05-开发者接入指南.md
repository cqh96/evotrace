## 1. Java 项目接入（Spring Boot Starter）

### 1.1 添加依赖

```xml
<dependency>
  <groupId>io.evotrace</groupId>
  <artifactId>evotrace-spring-boot-starter</artifactId>
  <version>0.1.0-SNAPSHOT</version>
</dependency>
```

### 1.2 配置

```yaml
evotrace:
  server-url: http://evotrace.internal:8080   # EvoTrace 服务端地址
  project-key: mall                            # 在控制台创建的项目标识
  app-key: ${spring.application.name}          # 应用标识
  api-key: evo_xxxx                            # 控制台生成的 API Key
  api-secret: xxxx                             # 控制台生成的 API Secret
  sensitive-key-pattern: "(?i).*(password|secret|token|key).*"  # 敏感Key脱敏规则
```

### 1.3 自动采集清单

Starter 在 `ApplicationReadyEvent` 后自动采集并通过虚拟线程上报：

| 采集器 | 内容 | 来源 |
| --- | --- | --- |
| `ApiInventoryCollector` | 接口路径/方法/出入参签名指纹 | `RequestMappingHandlerMapping` |
| `DependencyInventoryCollector` | 框架版本检测 | `Environment` 属性 |
| `ConfigInventoryCollector` | 配置 Key + 脱敏值哈希 | `ConfigurableEnvironment` PropertySource |

### 1.4 清单上报协议

```json
{
  "protocolVersion": "v1",
  "eventId": "<UUID>",
  "projectKey": "mall",
  "appKey": "order-service",
  "eventType": "INVENTORY_REPORT",
  "source": "JAVA_SDK",
  "payload": {
    "techStack": "Java/SpringBoot",
    "apis": [
      { "httpMethod": "POST", "path": "/order/create",
        "signatureHash": "a1b2c3d4", "schemaFingerprint": "" }
    ],
    "dependencies": [
      { "group": "org.springframework", "artifact": "spring-core",
        "version": "7.0.8", "scope": "compile" }
    ],
    "configFingerprints": {
      "application_yml.server.port": "8080",
      "application_yml.spring.datasource.password": "sha256:a1b2c3d4e5f6"
    }
  }
}
```

### 1.5 SPI 扩展

```java
@Component
public class CustomInventoryCollector implements InventoryCollector {
    @Override
    public String category() { return "CUSTOM"; }

    @Override
    public InventoryReportPayload collect() {
        // 采集自定义清单
        return new InventoryReportPayload(...);
    }
}
```

## 2. 多语言项目接入（CLI）

### 2.1 安装 CLI

```bash
# GraalVM Native Image 编译的单二进制文件
curl -L https://evotrace.internal/cli/evotrace-darwin-arm64 -o /usr/local/bin/evotrace
chmod +x /usr/local/bin/evotrace
```

### 2.2 CI 集成

```bash
# GitHub Actions
- name: EvoTrace Scan
  run: |
    evotrace scan --lang auto \
      --project-key mall \
      --api-key ${{ secrets.EVOTRACE_API_KEY }} \
      --server http://evotrace.internal:8080

# GitLab CI
evotrace_scan:
  script:
    - evotrace scan --lang auto --project-key mall --api-key $EVOTRACE_API_KEY
```

### 2.3 支持的语言

| 语言 | CLI 扫描内容 |
| --- | --- |
| Go | go.mod + gin/echo 路由 |
| Python | requirements.txt/pyproject.toml + FastAPI/Flask 路由 |
| Vue/Node | package.json + 约定目录 |
| Java | Maven/Gradle 构建文件（无 SDK 环境时使用） |

  Content type: application/json
  Events: Push / Pull request / Create (tag)

## 4. 开放 REST API 接入

任意系统按 [Envelope v1 协议](docs/03-API接口文档.md#11-上报事件) POST 到 `/open-api/v1/events`：

```bash
curl -X POST http://evotrace.internal:8080/open-api/v1/events \
  -H "X-EvoTrace-Api-Key: evo_xxxx" \
  -H "X-EvoTrace-Signature: <HMAC-SHA256>" \
  -H "Content-Type: application/json" \
  -d '{"protocolVersion":"v1","eventId":"...","projectKey":"mall",...}'
```

**HMAC 签名**：`HMAC-SHA256(apiSecret, requestBody)`，十六进制编码。

## 5. 事件类型参考

| eventType | 说明 | 典型 Payload |
| --- | --- | --- |
| `CODE_COMMIT` | Git commit/Push | `CodeCommitPayload` |
| `MR_MERGED` | Merge Request 合并 | `CodeCommitPayload` |
| `RELEASE_TAG` | Git Tag 推送 | `CodeCommitPayload` |
| `INVENTORY_REPORT` | 应用清单上报 | `InventoryReportPayload` |
| `CONFIG_CHANGE` | 配置变更 | 自定义 |
| `DDL_CHANGE` | 数据库结构变更 | 自定义 |
| `DEPLOY_RECORD` | 部署记录 | 自定义 |

## 7. 最佳实践

1. **API Key 管理**：每个环境（开发/测试/生产）使用独立的 API Key
2. **HMAC 签名**：生产环境务必开启签名校验，安全存储 apiSecret
3. **幂等性**：使用有意义且唯一的 `idempotencyKey`，推荐格式 `gitlab:project/123:push:<sha>`
4. **大文件**：diff 超过 256KB 时先上传到 `/blobs` 获取 `blobRef`，事件中只带引用
5. **隐私模式**：对包含敏感业务逻辑的项目设置 `STRUCTURE_ONLY` 或 `LOCAL_ONLY`
6. **定期轮换**：每季度轮换 API 凭证，`POST /projects/{key}/credentials/rotate`
